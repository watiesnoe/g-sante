# 01 — Accueil et secrétariat

Menus : **Dossiers Patients**, **Tickets**, **Rendez-vous**, **Caisse**.

## Recevoir un patient

1. **Nouveau patient ?** Créez d'abord son dossier : **Dossiers Patients → Liste des Patients** (nom, prénom, sexe, téléphone, âge, ethnie). Si l'établissement le demande, indiquez la **provenance** ; s'il vient d'un CSCom, précisez lequel.
2. Si l'application affiche « Un dossier existe peut-être déjà », **vérifiez la liste proposée** avant de confirmer. Un doublon disperse le dossier médical du patient.
3. **Dossiers Patients → Accueil / file d'attente → Enregistrer l'arrivée** : choisissez le patient, le service et le motif de venue.
4. Le patient entre dans la file d'attente avec le statut **Enregistré**.

**Patient dans un état grave** : prévenez immédiatement l'infirmier(e) ou le médecin de garde, qui l'inscrit au **registre des urgences**. Il est soigné d'abord ; le paiement est régularisé après.

Le numéro de dossier est attribué automatiquement. Notez-le sur le carnet du patient.

## Faire un ticket

1. **Tickets → Nouveau Ticket**.
2. Choisissez le patient et les prestations. Le prix est calculé automatiquement (tarif en vigueur, assurance, gratuité éventuelle) : vous ne le saisissez pas.
3. Si le patient est assuré, vérifiez la date de fin de prise en charge ; un ticket est refusé si elle est dépassée.
4. Choisissez le mode de paiement et enregistrez. **Votre caisse doit être ouverte** (voir guide 02).
5. Imprimez le ticket et remettez-le au patient.

Un ticket encaissé ne se modifie plus : en cas d'erreur, demandez au responsable de l'annuler, puis refaites-le.

## Rendez-vous

- **Rendez-vous → Agenda du jour** : la liste du jour, par médecin.
- À l'arrivée du patient, marquez le rendez-vous **Honoré** ; s'il ne vient pas, **Absent** ; s'il prévient, **Annulé**.
- Le patient reçoit un rappel par SMS la veille (quand l'envoi de SMS est activé).

## Fin de journée

- Vérifiez qu'aucun patient ne reste « Enregistré » dans la file sans avoir été vu.
- Comparez le nombre de patients avec le registre papier.
