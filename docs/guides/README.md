## À savoir avant de lire

- **Ce que vous voyez dépend de deux choses** : votre rôle, et les modules actifs de votre établissement (un cabinet n'a pas de maternité, un CSRéf n'a pas de bloc opératoire par défaut). Si un menu de ce guide n'apparaît pas chez vous, c'est normal : demandez à l'administrateur s'il doit être activé.
- **Rien ne s'efface.** Une erreur se corrige par une annulation (avec motif) ou un addendum ; l'original reste visible dans le journal d'audit.
- **Pendant le pilote**, continuez à tenir les registres papier en parallèle. Chaque soir, comparez le nombre de patients et le total de caisse entre le papier et l'application, et notez tout écart dans le cahier de suivi du pilote.
