# 04 — Infirmier(e)

Menus : **Dossiers Patients**, **Consultations** (suivi), **Urgences**, **Examens**, **Hospitalisations**, **Maternité** (CPN), **Personnel**.

## Tri à l'accueil

Si le tri est activé dans l'établissement :

1. **Dossiers Patients → Accueil / file d'attente**.
2. Évaluez le patient et passez-le au statut **Trié** en lui donnant une **priorité** :
   - **P1** — urgence vitale ;
   - **P2** — urgent ;
   - **P3** — peut attendre ;
   - **P4** — non urgent.
3. La file d'attente est classée selon cette priorité.

## Urgences

1. **Urgences** (ou le bouton rouge **Urgence** de l'écran d'accueil) : inscrivez le patient au registre des urgences.
2. **Prendre en charge** immédiatement. **Le paiement ne bloque jamais la prise en charge d'une urgence** : il est régularisé après.
3. Notez les soins et la décision (observation, hospitalisation, référence).

## Hospitalisés

- **Hospitalisations → État des lits** : lits libres, occupés, réservés, par service et par chambre.
- **Liste des hospitalisés** : notez les soins et observations du jour.

## Examens

Vous pouvez consulter les résultats validés dans le dossier du patient.

## Gardes

**Personnel → Gardes et astreintes** : votre planning de garde.

## Demande d'achat

Un produit manque dans le service : **Stock → Demandes d'achat**. La demande est approuvée par le responsable.
