# 00 — Premiers pas (tout le personnel)

## Se connecter

1. Ouvrez le navigateur sur l'adresse donnée par l'administrateur.
2. Saisissez votre e-mail et votre mot de passe.
3. Chaque agent a **son propre compte**. Ne prêtez jamais le vôtre : tout ce qui est fait est enregistré à votre nom (encaissements, prescriptions, validations).

**Mot de passe** : au moins 10 caractères. Changez-le depuis votre profil (menu en haut à droite).

**Compte verrouillé** : après 5 mots de passe erronés, le compte est bloqué 15 minutes. L'heure de déblocage s'affiche. En cas d'urgence, appelez l'administrateur.

**Déconnexion automatique** : sans activité pendant un certain temps (réglé par l'administrateur), vous êtes déconnecté. Fermez toujours votre session avant de quitter le poste.

## Choisir l'établissement

Si vous travaillez dans plusieurs établissements, le nom de l'établissement courant est affiché dans la barre du haut. Cliquez dessus pour en changer. **Vérifiez-le avant de travailler** : un patient enregistré dans le mauvais établissement n'apparaîtra pas dans l'autre.

## Se repérer

- **Menu de gauche** : les modules auxquels vous avez droit.
- **Tableau de bord** : les chiffres du jour selon votre rôle.
- **Recherche patient** : par nom, prénom, téléphone ou numéro de dossier.

## Le circuit d'un patient

```
Accueil (passage) → Caisse (ticket) → Consultation → Examens / Ordonnance
        → Pharmacie / Laboratoire → Sortie, hospitalisation ou référence
```

En urgence, le patient est pris en charge **d'abord**, le paiement vient après.

## En cas de problème

- Message « Accès non autorisé » : votre rôle n'a pas ce droit. Ne demandez pas le compte d'un collègue ; signalez-le à l'administrateur.
- Coupure de courant ou de réseau : notez sur le registre papier ce qui n'a pas pu être saisi, et saisissez-le dès le retour, en précisant l'heure réelle dans les observations.
- Toute anomalie : notez l'heure, l'écran et le message exact dans le cahier de suivi du pilote.
