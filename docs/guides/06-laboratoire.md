# 06 — Laboratoire et imagerie

Menu : **Examens (labo / imagerie)**. Les anciens écrans « Analyses supplémentaires » et « Réponses analyses » y sont regroupés.

## Le circuit d'un examen

```
Demandé → Prélevé (ou Planifié pour l'imagerie) → Réalisé → Résultat saisi → Validé
```

1. **Prélèvement** : le patient se présente, faites le prélèvement et marquez l'examen **Prélevé**.
2. **Saisie** : entrez le résultat. Pour les examens chiffrés, une valeur hors des normes est **signalée comme anormale**.
3. **Validation** : le responsable du laboratoire relit et **valide**. Le résultat n'apparaît au médecin qu'après validation.

## Filtres et impressions

- Filtre par statut : **À traiter** (par défaut), ou un statut précis (par exemple **Validé** pour retrouver les résultats rendus).
- Le médecin peut choisir **Mes prescriptions** pour ne voir que ses demandes.
- L'icône d'imprimante donne le **bon d'examens** de la consultation ; le lien « Voir le fichier » ouvre le compte rendu joint (PDF, image).

## Règles

- Un résultat **validé ne se modifie plus**. En cas d'erreur, signalez-le au responsable.
- Un examen annulé ne peut pas recevoir de résultat.
- Vérifiez toujours **l'identité du patient** (nom + numéro de dossier) avant de saisir un résultat.
